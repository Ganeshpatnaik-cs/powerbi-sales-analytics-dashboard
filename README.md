# Power BI Sales Analytics Dashboard

## Project Overview
An interactive Power BI dashboard designed to analyze retail sales performance, dynamic KPIs, and customer/category insights to drive data-backed business decisions.

## Key Features & Insights
* *Dynamic KPIs:* Real-time tracking of Total Sales, Profit Margin, and Units Sold.
* *Time Intelligence:* YoY (Year-over-Year) growth and period comparison using DAX measures.
* *Interactive Visuals:* Breakdown by Region, Category, and Top-performing Brands.

## Tech Stack & Tools
* *BI Tool:* Microsoft Power BI
* *Data Modeling:* Power Query, Star Schema
* *Calculations:* DAX (Data Analysis Expressions)
* *File:* runnning.pbix (Power BI Report File)
